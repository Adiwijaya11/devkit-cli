# DevKit — Developer Project Wizard

CLI tool untuk membantu developer membuat project, menginstall teknologi, mengecek environment, dan mencari command yang sering lupa.

## Instalasi

```bash
npm install -g devkit-tool
```

## Penggunaan

```bash
devkit
```

Atau tanpa install global:

```bash
npx devkit-tool
```

## Fitur
